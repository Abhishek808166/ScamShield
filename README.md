# 🛡️ ScamShield

### AI-Powered Scam, Phishing & Suspicious Message Detection

ScamShield is a cybersecurity web application that analyzes suspicious messages and identifies potential scam, phishing, social-engineering, and suspicious URL indicators.

It combines **rule-based detection, URL intelligence, and AI-powered analysis** to provide users with a clear risk assessment and practical safety recommendations.

---

## 🚀 Features

- 🔍 **Smart Scam Detection**
  - Credential requests
  - Financial requests
  - Fake prizes and rewards
  - Urgency and pressure tactics
  - Account threats
  - Impersonation attempts
  - Suspicious links

- 🔗 **URL Intelligence**
  - Suspicious domain detection
  - Shortened URL detection
  - IP-based URL detection
  - HTTP/HTTPS analysis
  - Suspicious URL keywords
  - Unusual subdomain detection

- 🤖 **AI Security Assessment**
  - Risk classification
  - Confidence score
  - Intent detection
  - Explanation of suspicious behavior
  - Safety recommendations

- 📊 **Risk Scoring**
  - Rule-based risk score
  - URL risk score
  - AI assessment
  - Combined risk assessment from 0–100

- 📈 **Scan Dashboard**
  - Total scans
  - High-risk scans
  - Medium-risk scans
  - Safe scans
  - Recent scan history

- ⚡ **Fast Web Interface**
  - Flask backend
  - HTML/CSS/JavaScript frontend
  - Real-time analysis
  - Responsive cybersecurity-focused UI
